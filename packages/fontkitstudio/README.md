# fontkitstudio

Font Kit Studio lets you try type on your own running web app, in development only. The
one-command form (`npx fontkitstudio`) arrives in 0.3.0; this release is the package
foundation.

`fontkit-bridge.js` belongs to Font Kit Studio. It is not part of, and has no relation to,
the `fontkit` font engine on npm.

See the [repository README](https://github.com/pterw/font-kit-studio#readme) for what Font
Kit Studio does and how to use it today.
