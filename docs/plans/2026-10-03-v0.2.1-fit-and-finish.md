## Global constraints

- Studio stays one HTML file; the bridge stays dependency-free; `serve.py` stays stdlib.
- Protocol v1 is not changed by this plan. Anything that needs a protocol change is out of
  scope and goes to the owner.
- Every behaviour change starts with a failing browser test; existing correct behaviour is
  characterized, never made RED. Tests assert what the user sees (rendered disabled state,
  visible text, computed style), not internal flags.
- Rule 6 (never silently overwrite) and Rule 7 (no third-party contact until asked) stay as
  they are. No task adds an automatic connect, an automatic font load or a browser that
  opens by default.
- Desktop-first (D029): fixes are verified at 1440, 1280 and 1024; 390 is advisory.

## Decisions taken in this plan

These were open in the audit. They are decided here so the tasks can run without a
round trip; the owner can overturn any of them before the task that uses it starts.

1. **All first-run paths are fixed, not one.** How the owner launched the demo is not
   known; the audit lists every path (file from disk, `serve.py`, busy port, remote host)
   and each gets a truthful message. Nothing is prioritised on a guess.
2. **No browser opens by itself.** `serve.py` prints one line, `Open: <Studio URL>`, as
   its last line, and gains `--open` to launch the default browser on request. Tests and
   CI start the server too; a default side effect there is wrong.
3. **A missing overrides file is served as empty CSS** (`200 text/css`, a one-line comment
   saying Sync to file writes it). `serve.py` never creates the file on start.
4. **Studio offers the demo instead of connecting to it.** When Studio is served by the dev
   server and has no `?target=`, it reads `/__fontkit/status` (same origin, already fetched
   for Sync) and prefills the Target URL with the demo address, with a button the user
   presses. From a file or another server, nothing is prefilled.
5. **The serif token comes from a role, never an index.** `--font-serif` falls back to the
   first slot whose family is in the serif category; when there is none, the token is not
   sent, so the page keeps its own serif stack.
6. **Cropped widths get a scrollbar, not a scale.** A preview wider than the stage scrolls
   horizontally with a visible scrollbar; the page is never scaled, because measurements
   in the inspector must match the page.
